# Study Apps

Study apps for psychiatry, psychology and science, built with Claude. Each one is a single self-contained `index.html` that runs in the browser.

**Open them live:** https://chuckhachem.github.io/study-apps/

| App | Live link | What it teaches |
|---|---|---|
| Psychiatry Mastery | [open](https://chuckhachem.github.io/study-apps/psychiatry-mastery/) | Board-level psychiatry: 2,425 questions, spaced repetition, memory hooks, receptor atlas, interview simulations and the Interview Playbook |
| Clinical Judgment Trainer | [open](https://chuckhachem.github.io/study-apps/clinical-judgment-trainer/) | What to say next, bedside pattern recognition and case simulations |
| Psychiatric Drug Reference | [open](https://chuckhachem.github.io/study-apps/psychiatric-drug-reference/) | Psychopharmacology by drug class: dosing, pearls, warnings and a board-level quiz |
| LU M1 Clinical Psychology | [open](https://chuckhachem.github.io/study-apps/lu-m1-clinical-psychology/) | The Lebanese University M1 Clinical Psychology courses as MCQ practice |
| Chemistry & Physics Foundations | [open](https://chuckhachem.github.io/study-apps/chemistry-physics-foundations/) | Chemistry and physics from zero to tutor level |

Progress is saved in the browser you use. The AI features (the drug reference's assistant, the LU M1 coach) only work in the Claude versions.
