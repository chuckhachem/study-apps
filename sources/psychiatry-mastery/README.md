# Praxis

A psychiatry study app with board-level questions, spaced repetition, memory hooks, a receptor atlas, interview simulations and an Interview Playbook (what to say, when, and what to watch for). It's one self-contained `index.html`, so you just open it in a browser.

Live app: https://chuckhachem.github.io/Praxis/

## Files

- `index.html`: the complete app. Open it, host it, or hand it to any AI to run as-is.
- `data/praxis-bank.json`: all of the app's content (2,425 questions, hooks, diagrams, atlas, simulations, and the Interview Playbook) as clean JSON.
- `PROMPT.md`: a copy-paste prompt that gets any AI to rebuild Praxis from scratch using the data file.
